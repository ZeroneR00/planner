## Только для Claude Code

- Для задач больше одного файла начинай с Plan Mode и показывай план — кроме выполнения утверждённого `docs/PLAN.md`.

## Работа по сессиям (экономия токенов)

Планирование и выполнение — в разных сессиях.

- **Сессия планирования.** План этапа — в Plan Mode, с вопросами по продукту. После «ок» записываю его в `docs/PLAN.md` самодостаточным: решения, файлы, сигнатуры, нужные куски SPEC и прототипа, тест-кейсы, проверки, сообщение коммита. Коммит «Документация: план этапа N».
- **Сессия выполнения** начинается с кодового слова («погнали», «продолжай») — это и есть «ок».
  - Читаю `docs/PLAN.md` и делаю. Plan Mode не включаю.
  - SPEC, прототип и код целиком не перечитываю: читаю только то, что меняю, и места, на которые ссылается план.
  - Не перепроверяю себя сверх `lint` / `typecheck` / `test`; не перечитываю файл после записи.
  - Если реальность разошлась с планом — решаю сам в духе плана и коротко пишу об этом в итоге. Спрашиваю, только если это задевает продукт.
- **Конец этапа:** проверки → коммит (этап без UI — сразу, с UI — после «работает» с телефона) → в `docs/PLAN.md` статус «выполнен, коммит …».
