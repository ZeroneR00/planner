# Прототип

Скриншоты экранов из дизайна (390×844, @2x) и исходник интерактивного прототипа.
Это образец внешнего вида и поведения, а не код проекта. Описание — в `docs/SPEC.md`.

| Файл | Что показывает | Раздел SPEC |
|---|---|---|
| `01-today.png` | Главный экран «Сегодня»: Сейчас, Карман, Дальше сегодня | Главный экран |
| `02-date-from-text.png` | «каждый вторник вынести мусор» — дата и повтор поняты из текста | Разбор даты из текста |
| `03-chips-manual.png` | День выбран в бегунке вручную | Запись задачи |
| `04-repeat.png` | Список повторов за кнопкой ↻ | Запись задачи |
| `05-calendar.png` | Календарь для далёкой даты | Запись задачи |
| `06-ahead.png` | Экран «Впереди» и раздел «Повторяется» | Экран «Впереди» |
| `planner-prototype.dc.html` | Исходник прототипа: тексты, размеры, логика (в т.ч. `parse()` — разбор дат) | — |

Чего нет на скриншотах (смотри SPEC): режим правки, плашка «Вернуть» с таймером, затухания краёв бегунка.
