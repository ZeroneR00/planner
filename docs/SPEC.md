# SPEC — Планировщик дня

Источник правды о продукте. Если код расходится со SPEC — это баг либо повод обсудить и обновить SPEC.
Платформа: React Native (Expo), Android в первую очередь, iOS — следом.
Интерактивный образец всех решений: `docs/prototype/planner-prototype.dc.html` (HTML на рантайме дизайн-холста; читать как образец поведения, текстов и размеров).

## Зачем

Старые планировщики раздражали количеством нажатий: записать задачу было дольше, чем её сделать.
Здесь мысль записывается за 2–3 секунды, прямо во время другой работы, а решение «когда» можно отложить.

Принципы:
1. **Запись — без решений.** Написал, «Отправить» — готово. Всё остальное по желанию.
2. **Одно поле ввода на всё приложение.** Там же пишем новое и правим старое.
3. **Ничего не исчезает незаметно.** Выполненное остаётся зачёркнутым, удалённое можно вернуть.
4. **Никаких «Вы уверены?».** Вместо подтверждений — отмена после действия.
5. **Один предмет — одно название.** Кнопка и раздел, куда она ведёт, называются одинаково.

## Словарь

| Термин | Что это |
|---|---|
| **Стикеры** | Задачи без дня, сюда падает всё по умолчанию; висят, пока не уберёшь или не поставишь день. Раньше «Карман», «Скинуто» |
| **Сейчас** | Крупная карточка: первая несделанная задача на сегодня |
| **Дальше сегодня** | Остальные задачи дня: сначала несделанные, внизу — выполненные |
| **Впереди** | Экран будущего: задачи по дням + раздел «Повторяется» |
| **Бегунок** | Горизонтальный ряд чипов «когда» над полем ввода |
| **Повтор (правило)** | «Каждый вт» и т.п. Одно правило, а не копии задачи |

## Главный экран («Сегодня»)

Сверху вниз:
1. **Шапка**: дата («Суббота, 17 октября»), заголовок «Сегодня», справа кнопка «Впереди N».
2. **Сейчас**: метка «Сейчас» + «сделано N»; текст задачи крупно; кнопки «Сделано» и «Позже» (переносит задачу в конец дня). Если задач нет — «На сегодня всё. Можно выдохнуть.»
3. **Стикеры · N** + подсказка «тапни текст, чтобы изменить». У строки: текст, «Когда?», ×. «Когда?» открывает меню: Сегодня / Завтра / Выбрать дату…; выбор переносит стикер и показывает плашку «Вернуть».
   Вернувшиеся задачи помечены «↩ вчера не отмечено» и имеют кнопку ✓ «Уже сделал».
4. **Дальше сегодня**: кружок-галочка + текст (+ «↻ каждый день» у повторов).
   Выполненные остаются в списке внизу: зелёная галочка, зачёркнутый текст, у повторов «↻ каждый день · на сегодня готово».
5. **Футер** (всегда над клавиатурой): поле ввода + кнопка справа (микрофон, когда пусто; стрелка, когда есть текст; ✓, когда идёт правка).

## Запись задачи

- Поле: плейсхолдер «Запиши мысль — разберёшь потом». Кнопка «Отправить» на клавиатуре или стрелка — добавить. После добавления фокус остаётся в поле, чтобы можно было записать следующую мысль сразу.
- **Бегунок появляется только когда в поле есть текст.** Чипы: `В стикеры` (выбран по умолчанию) · `Сегодня` · `Завтра` · ближайшие 5 дней (`Пн 19`) · `Дата` (календарь месяца).
  Если ничего не трогать — задача уходит в стикеры.
- **↻ справа от бегунка** — повтор. Неактивна, пока выбран «В стикеры». Открывает список: Один раз · Каждый день · По будням · Каждую неделю · по вторникам · Каждый месяц · 20-го · Каждый год · 20 октября.
  - Пункт «Каждую неделю» показывает текущие дни: «по вторникам» или «по ср и чт». Тап — один тап, меню закрывается.
  - **Под ним — ряд дней `Пн Вт Ср Чт Пт Сб Вс`**, виден всегда. Тап по дню включает или выключает его, меню не закрывается (закрывается тапом по ↻, полю или ✓). Был повтор не еженедельный — становится еженедельным только с этим днём; выключили последний день — «Один раз».
  - Начало повтора — ближайший отмеченный день, начиная с выбранного чипа: выбрана суббота, отмечены ср и чт — начало в среду. Считается от выбранного чипа, а не от прошлого сдвига.
  - Тап по чипу дня, которого нет среди отмеченных, — повтор по этому одному дню (побеждает последнее действие); чип из отмеченных — дни остаются.
- **Строка-подсказка над полем** говорит, как приложение поняло ввод:
  `→ вт, 20 октября · ↻ каждый вт · понял из текста` или `Упадёт в стикеры, разберёшь потом`.
- После добавления строка показывает итог: «Запланировано: вт, 20 октября», «Добавлено на сегодня» и т.п.

### Бегунок: поведение

- Горизонтальный `ScrollView`, листается пальцем, индикатор прокрутки виден.
- Справа край растворяется (намёк «есть ещё»): поверх ряда градиент от цвета футера к прозрачному.
- Слева затемнение появляется **постепенно** по мере прокрутки (0 → полная сила за первые ~25dp прокрутки), примерно вдвое слабее и уже правого (~10dp), с плавной кривой. В начальном положении слева затемнения нет.
- Если день выбран из текста или правки и чип за краем — ряд сам доезжает до выбранного чипа.

### Разбор даты из текста

Фраза распознаётся, вырезается из названия, и бегунок переключается сам.

| Пишешь | Результат |
|---|---|
| `сегодня`, `завтра`, `послезавтра` | +0 / +1 / +2 дня |
| `в/во <день недели>`, `в пт` | ближайший такой день. **Если сегодня тот же день недели — следующая неделя** («в субботу», написанное в субботу = через 7 дней; для сегодня есть слово «сегодня») |
| `через день`, `через 3 дня`, `через неделю`, `через 2 недели` | сдвиг |
| `27 августа`, `27.08` | дата; если уже прошла в этом году — следующий год |
| `каждый/каждую/каждое <день недели>`, `по вторникам` | еженедельный повтор, начиная с ближайшего такого дня **включая сегодня** |
| `каждую среду и четверг`, `по средам и четвергам`, `каждый пн, ср и пт` | повтор по нескольким дням недели, начиная с ближайшего из них |
| короткие `пн`, `вт`, `ср`, `чт`, `пт`, `сб`, `вс` | то же, что полные названия дней |
| `каждое 27 августа`, `27 августа каждый год`, `каждый год 27 августа` | ежегодно, с ближайшего 27 августа |
| `каждый год`, `ежегодно` | ежегодно с сегодня |
| `каждый день`, `ежедневно` | ежедневно с сегодня |
| `по будням`, `каждый будний день` | пн–пт |
| `каждое 1 число`, `каждое 15-е` | ежемесячно |

Правило конфликтов: **побеждает последнее действие.** Выбрал чип вручную — он главнее текста. Потом дописал в текст новую дату — текст снова главнее.
Готовая реализация разбора (JS) есть в прототипе — метод `parse()`; перенеси в `src/lib/parse-when.ts` и покрой тестами.

### Полные даты и время

Дату и время можно написать или надиктовать целиком — микрофоном клавиатуры, а потом своей кнопкой (см. «Голос»). Разбор — свой, на правилах, без интернета.

| Пишешь / говоришь | Результат |
|---|---|
| `27 августа 2027`, `27.08.2027` | дата с годом |
| `двадцать седьмого августа`, `в три часа дня` | числа словами — как цифрами |
| `через месяц`, `через 2 месяца` | сдвиг; если такого числа нет — последний день месяца |
| `в следующий вторник`, `на выходных` | какой день имеется в виду — уточнить при планировании |
| `в 15:00`, `в 15.30`, `в 15` | время |
| `в 3 часа дня`, `в 9 утра`, `в 7 вечера`, `в 2 ночи`, `в полдень`, `в полночь` | время |
| `утром`, `днём`, `вечером` | фиксированные часы — какие, уточнить при планировании |
| `через полчаса`, `через 30 минут`, `через 2 часа` | время от текущего момента (может перейти на завтра) |

- Дата и время — независимые фразы: `завтра в 9 утра`, `в пятницу в 15:00`, `каждый вт в 9`.
- **Час без уточнения: 1–7 — днём** (`в 3` = 15:00), 8–23 — как есть.
- **Время без даты — сегодня, а если это время уже прошло — завтра.** Задача со временем в стикеры не падает.
- Подсказка показывает время: `→ сб, 25 октября · 15:00 · понял из текста`.
- Голосовой ввод ставит знаки препинания: точка, запятая, `?`, `!` рядом с фразой не мешают её распознать, а повисший знак убирается из названия («позвонить маме завтра.» → «позвонить маме»).

## Правка

- **Тап по тексту любой задачи** (Сейчас, Стикеры, Дальше сегодня, Впереди, Повторяется) — текст уходит в то же нижнее поле, поле получает фокус, курсор в конец.
- Задача в списке подсвечивается тонкой рамкой акцентного цвета, рамка поля тоже акцентная.
- Над полем: «✎ Правка» (или «✎ Правка повтора») и кнопка «Отмена». Кнопка отправки — ✓ «Сохранить» (неактивна при пустом тексте).
- Бегунок показывает текущий день задачи: в одном действии можно и исправить текст, и перенести, и включить повтор.
- Отмена: кнопка «Отмена», системная кнопка «Назад» на Android, **или повторный тап по той же задаче**.
- Правка повтора меняет правило для всех будущих экземпляров (строка-подсказка: «· для всех повторов»). «Один раз» в ↻ — повтор останавливается, сегодняшний экземпляр становится обычной задачей.
- Двойной тап для правки **не используем**: его не угадать и легко промахнуться. Случайный одиночный тап ничего не меняет.

## Отмена действий (плашка «Вернуть»)

Для действий, после которых что-то исчезает с экрана: × в стикерах и во «Впереди», «Остановить» у повтора, «Уже сделал» в стикерах, перенос стикера через «Когда?», перенос задачи на другой день в правке.
**Отметка галочкой плашку не вызывает** — выполненное остаётся на виду, повторный тап снимает галочку.

Плашка:
- текст «Убрано: Купить батарейки» / «Сделано: …» / «На завтра: …» / «Повтор остановлен: …» + надпись «Вернуть» справа;
- **тап по всей плашке = «Вернуть»**;
- слева круглый таймер как в Telegram: цифра 5…1, обводка тает по кругу (SVG-круг + анимация);
- внизу плашки тонкая полоска акцентного цвета, убегает вместе с таймером;
- полупрозрачная, без размытия; **парит над списком** чуть выше футера, не сдвигая разметку;
- последние 1,5 с плавно гаснет;
- 5 секунд; «Вернуть» восстанавливает состояние до действия; новое действие заменяет плашку.

## Экран «Впереди»

- Шапка: «‹» назад и заголовок «Впереди». Системный «Назад» тоже возвращает на «Сегодня».
- Группы по дням: «Завтра, вс, 18 октября», «Вт, 20 октября»… Строка: текст, ×. Только несделанные задачи с датой после сегодня; повторы в днях не показываются. Дней нет — пунктирная плашка «Пока ничего не запланировано».
- Раздел **«Повторяется»**: ↻, текст, подпись «каждый вт · следующий — вт, 20 октября», кнопка «Остановить». Повторов нет — раздела нет.
- «Остановить» выключает повтор; сегодняшний экземпляр остаётся обычной задачей.
- Поле ввода внизу работает и здесь.

## Время и напоминания

- Время задачи видно в строке, в «Сейчас» и во «Впереди» (JetBrains Mono, вторичный цвет).
- Есть время — есть напоминание: в это время приходит уведомление с текстом задачи, тап открывает приложение. Уведомления локальные, без сервера — `expo-notifications`.
- Разрешение на уведомления спрашиваем при первой задаче со временем, а не при запуске.
- Отметил «Сделано», убрал, перенёс или поменял время — напоминание отменяется или переставляется. Повтор со временем напоминает в каждый свой день.
- Android может придержать уведомление, пока телефон спит; точно до минуты — в собранном APK, через «точные будильники».
- Уточнить при планировании: порядок задач со временем внутри дня; как убрать или поменять время при правке; работают ли локальные уведомления в Expo Go на текущем SDK (если нет — этап напоминаний переезжает после development build).

## Смена дня (rollover)

Выполняется при запуске, при возврате приложения на передний план (`AppState` → `active`) и в полночь, если приложение открыто.
- Несделанная задача с прошедшей датой → **в стикеры** с пометкой «↩ вчера не отмечено» (иногда дело сделано, но не отмечено — поэтому кнопка «Уже сделал»).
- Повтор: в каждый подходящий день в «Сегодня» появляется экземпляр. Отметка экземпляра не трогает правило.
- Пропущенный экземпляр повтора → в стикеры, но **не больше одного на правило**: новый пропуск заменяет старый.
- Выполненные задачи прошлых дней в «Сегодня» не показываются (хранятся для истории).

## Голос

Кнопка микрофона, когда поле пустое. Распознавание на устройстве через `expo-speech-recognition`, язык `ru-RU`. Распознанный текст разбирается как обычный ввод и сразу добавляется («каждый вторник вынести мусор» — и готово). В режиме правки распознанный текст подставляется в поле.
Модулю нужен **development build** (в Expo Go не работает), поэтому это поздний этап. До него кнопка микрофона не показывается.

## Модель данных (v1, SQLite)

```ts
type Task = {
  id: string;             // uuid
  title: string;
  date: string | null;    // локальная дата 'YYYY-MM-DD'; null = в стикерах
  done: boolean;          // в SQLite — INTEGER 0/1
  doneAt?: string;        // ISO
  time?: string;          // локальное время 'HH:MM'; есть время — есть напоминание
  order: number;          // порядок внутри дня («Позже» = в конец)
  ruleId?: string;        // экземпляр повтора
  returned?: boolean;     // вернулась в стикеры неотмеченной
  createdAt: string;
  updatedAt: string;
};

type Rule = {
  id: string;
  title: string;
  kind: 'daily' | 'weekdays' | 'weekly' | 'monthly' | 'yearly';
  startDate: string;      // 'YYYY-MM-DD'
  weekdays?: number[];    // 0–6, для weekly; по возрастанию, хотя бы один
  month?: number;         // 1–12, для yearly
  monthDay?: number;      // 1–31, для monthly и yearly
  time?: string;          // 'HH:MM' — переходит в экземпляры
  active: boolean;
};
```

- Таблицы `tasks` и `rules`. Версия схемы — через `PRAGMA user_version`, миграции по порядку в `db.ts`.
- Колонки в SQLite — snake_case; `order` → `sort_order` (ORDER — слово SQL).
- Экземпляры повторов создаются **лениво**: при смене дня создаётся экземпляр на сегодня, если правило срабатывает и экземпляра `(ruleId, date)` ещё нет.
- Во «Впереди» ближайшая дата повтора вычисляется из правила, а не хранится копией.
- monthly: если числа нет в месяце — последний день месяца.
- yearly: 29 февраля в невисокосный год — 28 февраля.

## Этапы

0. Скелет: `create-expo-app`, TS strict, Jest, ESLint, шрифты, `theme.ts`, пустой тёмный экран; запуск в Expo Go на телефоне.
1. Логика без UI + тесты: `dates`, `parse-when`, `rules`, `rollover`.
2. База: `expo-sqlite`, схема, миграции, хуки чтения/записи.
3. Главный экран на реальных данных: Сейчас, Стикеры, Дальше сегодня.
4. Запись: поле над клавиатурой, бегунок с затуханиями, строка-подсказка, ↻, календарь.
5. Правка по тапу.
6. Плашка «Вернуть» (таймер, полоска), «Стикеры», меню «Когда?».
7. Экран «Впереди» и «Повторяется».
8. Повтор по нескольким дням недели: «каждую ср и чт», «по средам и четвергам» — из текста и в меню ↻; подписи и «Впереди» тоже. Плюс «Каждый год».
9. Полные даты и время из текста: год, числа словами, время, знаки препинания от голосового ввода; время хранится и видно у задачи, в том числе во «Впереди». Разбор — по самым частым способам сказать дату и время; примеры фраз у пользователя не спрашиваем.
10. Напоминания (`expo-notifications`), в том числе повторяющееся напоминание каждые N часов («пить воду») — детали при планировании.
11. Смена дня (`AppState`, полночь).
12. Development build + голос.
13. Сборка APK для себя и установка на телефон.
14. Работа над ошибками после использования, в том числе фразы с датой и временем, которые разбор не понял.

Потом (не v1):
- **Виджет на рабочий стол Android** с быстрым вводом — главный кандидат на следующую версию, прямо продолжает идею «записал за 2 секунды».
- iOS: сборка и проверка на iPhone.
- Синхронизация между устройствами.
