# Журнал решений

Формат: дата — что решили — почему. Новые записи сверху.

## 2026-10-19 — этап 1 (логика без UI)

- **«Каждое 31-е» в коротком месяце — последний день месяца** — иначе повтор молча пропадал бы в ноябре и феврале. То же для 30-го и 29-го.
- **Функции в `src/lib` чистые, `today` приходит параметром** — тесты не зависят от реального времени; `today()` вызывают только хуки.
- **Арифметика дат — через UTC на строках `'YYYY-MM-DD'`** — переход на летнее время и полночь не сдвигают дату. Локальный пояс трогает только `today()`.
- **`Rule` — дискриминированное объединение** (`RepeatPattern & {…}`), а не плоский тип со всеми полями — TS сам следит, что у `weekly` есть `weekday`, а у `monthly` — `monthDay`. В SQLite колонки остаются плоскими.
- **`parseWhen` возвращает дату, а не сдвиг в днях** — дальше её не нужно пересчитывать, и «27 августа» выражается так же, как «завтра».
- **Если матчер вернул `null`, разбор идёт к следующему** — в прототипе цепочка обрывалась, и «каждое 32 число» глушило остальные правила.
- **Исправлена ошибка прототипа с 29 февраля** — для следующего года не проверялось, существует ли дата, и получалось 1 марта.
- **Из текста берётся только первая фраза по порядку матчеров** — «завтра во вторник» → вторник, слово «завтра» остаётся в названии. Два «когда» в одной записи — редкость, а предсказуемость важнее.

## 2026-10-18 — этап 0 (скелет)

- **Экраны в `src/app/`, а не в `app/`** — так кладёт шаблон Expo SDK 58; весь код в `src/`, алиас `@/` → `src/`. Раздел «Структура» в AGENTS.md обновлён.
- **Убраны демо-пакеты шаблона и web** (`@expo/ui`, `expo-glass-effect`, `expo-symbols`, `expo-device`, `expo-image`, `expo-web-browser`, `react-native-web`, `react-dom`) — приложение только для телефона, web с `expo-sqlite` без доп. настройки не работает. Часть из них остаётся в `node_modules` как необязательные зависимости `expo`/`expo-router`, но наш код их не импортирует.
- **Шрифты грузятся в рантайме через `useFonts`**, сплэш держится до загрузки — встроить их в сборку (config plugin `expo-font`) можно только в development build, а мы в Expo Go. Импорт по начертаниям (`@expo-google-fonts/golos-text/600SemiBold`), чтобы в сборку не попадали неиспользуемые файлы.
- **В `theme.ts` добавлены цвета из прототипа, которых не было в AGENTS.md**: `textHint`, `outline`, `control`, `disabled`, `surfaceSelected`, `danger` — иначе их пришлось бы вписывать в компоненты «магией».
- **`noUncheckedIndexedAccess`** в tsconfig — `arr[i]` и группы регулярок имеют тип `T | undefined`; в `parse-when` это ловит обращения к несуществующей группе.
- **`types: ["jest"]`** в tsconfig — в TypeScript 6 глобальные типы из `@types/*` больше не подключаются автоматически.
- **Правила AGENTS.md в ESLint** без новых пакетов: запрет `any`, `window`/`document`/`localStorage` и hex-цветов вне `theme.ts`.
- **Имена файлов — kebab-case** — Windows не различает регистр, переименования вида `nowCard.tsx` → `NowCard.tsx` ломают git.

## 2026-10-17 — платформа

- **React Native (Expo) вместо PWA на Next.js** — главная ценность приложения в скорости записи, а самые быстрые способы записи нативные: виджет на рабочем столе и локальные напоминания без сервера. PWA этого не умеет. Опыт RN у меня уже был.
- **Expo Go на старте, development build — позже** (голос, виджет) — чтобы как можно дольше разрабатывать без тяжёлых сборок при слабом интернете.

## 2026-10-17 — дизайн-сессия

- **Вариант «Записать и разобрать потом»** вместо «строки ввода с временем по часам» — запись без решений быстрее, решение «когда» откладывается.
- **Бегунок «когда» появляется только при вводе**, по умолчанию «В карман» — пустой экран остаётся чистым, нулевой сценарий не требует ни одного лишнего тапа.
- **Повтор спрятан за ↻** — нужен редко, не должен мешать.
- **Несделанное уходит в Карман**, а не переносится на завтра — хвост не копится; кнопка «Уже сделал» — потому что иногда дело сделано, но не отмечено.
- **«В субботу», написанное в субботу, = следующая суббота** — для сегодня есть слово «сегодня».
- **Выполненное остаётся видимым зачёркнутым** — приятно видеть сделанное; у повторов видно, что завтра будет снова.
- **Отмена вместо подтверждений**: плашка «Вернуть» с таймером 6 с — правильное нажатие ничего не стоит, случайное исправляется одним тапом.
- **Правка — тап по тексту, в том же поле ввода**; не двойной тап — его не угадать и легко промахнуться.
- **Название «Карман» — рабочее**: «Скинуто» отклонено (двусмысленно), «Потом» не прижилось как название раздела.
